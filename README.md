# 慢慢打・台灣麻將

公開遊戲：https://sharkday27.github.io/taiwan-mahjong/

適合手機與中老年玩家的單一 HTML 台灣十六張麻將遊戲，不需要登入或安裝依賴。

## 操作與功能

- 直向模式手牌與出牌操作常駐下方，牌桌獨立顯示，避免整頁來回滑動。
- 橫向模式牌桌與手牌左右並排；極小螢幕必要時只在各區域內捲動。
- 所有棄牌依打出順序集中展示並換行，牌多時可在棄牌區內捲動。
- 規則與重新開局移到頂端「選單」，理牌與選牌建議放在手牌工具列。
- 查看選單時暫停電腦操作，關閉後繼續。


- 大牌面、大按鈕、可放大文字，點選後確認出牌；完全沒有玩家操作倒數。
- SVG 萬筒索字花牌圖案，牌下方没有文字標籤。
- 手指按住手牌可跨排拖曳排序，拖曳不會出牌；手動順序保存、新摸牌接在最後，可按「理牌」還原。
- 新摸的牌標亮金黃色、保留間距，移動時標示跟隨該張牌。
- 四家副露顯示有厚度的麻將牌組，槓牌第四張疊在上方；其他玩家的暗槓牌面遮蔽。
- 吃、碰、槓、胡牌以非模態彈出提示卡詢問，提示卡佔用獨立版面，不遮住麻將、不鎖住手牌排序。
- 自由對局，牌局和虛擬金幣保存在目前瀏覽器。
- 發牌、摸牌、打牌、吃碰槓、補花與胡牌動畫和合成音效。
- 音量按鈕位於字體大小按鈕左邊，點開視窗後調整音量或試聽，設定自動保存。
- 第一次點擊或鍵盤操作後啟用聲音；音量可調到0，支援減少動態效果設定。

## 虛擬金幣

每家起始5,000枚，一底100枚，每台50枚。可免費為四家各補充3,000枚，純練習用途，不可兌換現金。

放槍者單獨付款；自摸由三家各付。每筆為 `100 + 台數 × 50`，依該付款對是否包含莊家加計莊家1台與每次連莊2台。金幣不足付至零，沒有負債或手續費。

莊家胡牌或流局連莊；其他人胡牌則輪至下一家，每四次輪莊切換圈風。流局不收付。結算逐項列明牌型、台數、付款公式和玩家金幣變動。重載不會重複收付，重新開局不清除金幣。

## 本桌計台表

台灣各地算法不同，本桌採固定常見表，遊戲內可查看全部規則。

| 項目 | 台數 |
| --- | ---: |
| 門清／自摸 | 各1 |
| 門清一摸三 | 3（取代門清、自摸） |
| 三元刻子、門風刻子、圈風刻子 | 各1 |
| 正花、花槓 | 每張正花／每組花槓各1 |
| 槓上開花或補花自摸、海底撈月 | 各1 |
| 搶槓胡 | 1，由加槓者付款 |
| 單吊、卡張、邊張 | 最多1，須唯一進張 |
| 平胡 | 2（無字無花、全順子、非自摸且兩面多進張） |
| 全求人 | 2（不另計單吊） |
| 三暗刻／四暗刻／五暗刻 | 2／5／8 |
| 碰碰胡 | 4 |
| 混一色／清一色／字一色 | 4／8／8 |
| 小三元／大三元 | 4／8（不另計三元刻子） |
| 小四喜／大四喜 | 8／16（不另計風刻子） |
| 莊家、連莊 | 涉莊時1台＋每次連莊2台 |

同一副牌採最高台數的有效拆解。字一色、五暗刻不另計碰碰胡；暗槓不破門清，放槍補成的刻子不算暗刻。

## 規則範圍

支援吃、碰、明槓、暗槓、加槓、搶槓胡、自摸與放槍胡牌，五組面子加一對將眼。電腦也會吃碰槓。摸牌後手上有已碰牌的第四張時，可加槓：將第四張疊在原牌組上，從牌尾補牌；其他玩家可搶槓胡，若被搶胡則保留原碰牌、不補牌。胡牌優先，碰槓其次，再來吃牌；同等優先按距離出牌者的下家順序處理。

七搶一／八仙過海特殊花胡、過水限制，以及天胡／地胡／人胡等首巡特殊牌型尚未實作，不計入台數。

## 檔案與驗證

HTML、CSS、SVG、JavaScript 和音效均包含在 index.html，下載後可離線遊玩。

已透過 Node 檢查100局牌局、手牌數量、基本胡牌與拖曳排序，另檢查計台排除條件、進張、涉莊加台、加槓補牌與搶槓胡、放槍／自摸支付、金幣守恆、餘額不足、單次結算、重載復原與莊家圈風輪替。手機上的觸控觀感、布局與聲音仍需實機驗證。

GitHub Pages 從 main 分支根目錄發布，更新 main 後公開遊戲會自動部署。
