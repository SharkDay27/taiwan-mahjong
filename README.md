# 慢慢打・台灣麻將

適合手機與中老年玩家的單一 HTML 麻將練習遊戲。

## 開啟遊戲

線上版：https://easy-mahjong.qaz70725.chatgpt.site

下載 index.html，用瀏覽器開啟即可遊玩，不需要安裝依賴或額外音檔。

## 功能

- 台灣十六張、三位電腦對手、自動補花與基本胡牌判定。
- 大牌面、大按鈕、可放大文字，點牌後確認打出。
- 完全沒有玩家出牌或吃碰胡倒數。
- SVG 萬筒索字花牌圖案，牌下方沒有文字標籤。
- 五關挑戰與自由練習，牌局和進度存在目前瀏覽器。
- 發牌、摸牌、打牌、吃碰槓、補花與胡牌的動畫和合成音效。
- 第一次點擊或鍵盤操作後啟用聲音；音量可調到0，音量設定自動保存。
- 支援 prefers-reduced-motion 減少動態效果設定。

## 規則範圍

這是基本牌型休閒練習版。支援吃、碰、明槓、暗槓、自摸與放槍胡牌，五組面子加一對將眼。電腦以摸打、碰與胡牌為主。

尚未加入完整地方計台、七搶一／八仙過海特殊花胡、過水限制、加槓、搶槓胡、連莊與完整圈風流程。不涉及金錢或下注。

## 原始碼與驗證

所有 HTML、CSS、SVG 與 JavaScript 均包含在 index.html。

已用 Node 模擬100局牌局，檢查手牌數量、基本胡牌判定、關卡事件與流程能否結束。動畫實際觀感及聲音仍需手機瀏覽器驗證。

目前 GitHub 原始碼與 Sites 線上版本由維護者同步發布，沒有設定 GitHub 推送後自動部署。
